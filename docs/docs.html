Getting Started with FlatFree

FlatFree is a community-maintained Flatpak repository. This documentation will help you get started with using and contributing to FlatFree.

What is Flatpak?

Flatpak is a next-generation packaging format for Linux desktop applications. It provides sandboxing, cross-distribution compatibility, and automatic updates. FlatFree provides a repository of Flatpak applications that are free and open source.

Adding the FlatFree Repository

flatpak remote-add --if-not-exists flatfree https://natalie.acreetionos.org/FlatFree/flatfree.flatpakrepo

Installing Applications

flatpak install flatfree org.acreetionos.MediaWriter

Running Applications

flatpak run org.acreetionos.MediaWriter

Listing Available Applications

flatpak remote-ls flatfree

Updating Applications

flatpak update

Creating a Flatpak Manifest

To submit an application to FlatFree, you need a flatpak-builder manifest. Here is a basic example:

{
  "id": "org.example.App",
  "runtime": "org.gnome.Platform",
  "runtime-version": "46",
  "sdk": "org.gnome.Sdk",
  "command": "myapp",
  "finish-args": [
    "--share=ipc",
    "--socket=x11"
  ],
  "modules": [
    {
      "name": "myapp",
      "buildsystem": "meson",
      "sources": [
        {
          "type": "git",
          "url": "https://github.com/example/myapp.git"
        }
      ]
    }
  ]
}

Place this manifest in a directory named after your app ID (e.g., org.example.App/org.example.App.json) and submit a pull request.
