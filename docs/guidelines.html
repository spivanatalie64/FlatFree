Rules for submitting applications to FlatFree

Our Guidelines

FlatFree has simple, straightforward guidelines. We believe in freedom, not gatekeeping.

  • Free Software Only. All applications must be free and open source software. Any OSI-approved license is acceptable.
  • Any Tooling Welcome. Applications created with AI assistance are fully accepted. We do not police how code is written.
  • Must Build Successfully. Your flatpak-builder manifest must produce a working Flatpak package. Our CI will verify this.
  • Malware Scan Required. All submissions are automatically scanned for malware. Any threats will be rejected.
  • No Human Reviewers. There is no review board. If your app passes CI, it's published automatically.
  • Respect User Freedom. Applications must not spy on users, exfiltrate data, or contain tracking without clear disclosure.

To submit, open a pull request on our GitHub repository with a directory containing your app ID and a flatpak-builder manifest.

FlatFree is not affiliated with Flathub or the Flatpak project.
